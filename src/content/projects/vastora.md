Vastora is Petauron's current and only product.

## Product structure

Vastora Center and Vastora Agent are the two public product components.

## Center–Agent architecture

Vastora Center provides the centralized Control Plane. Vastora Agent runs on each managed Node and connects that Node to the Control Plane.
