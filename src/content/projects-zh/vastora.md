Vastora 是 Petauron 当前唯一的产品。

## 产品构成

Vastora Center 与 Vastora Agent 是两个对外产品组件。

## Center–Agent 架构

Vastora Center 提供集中式 Control Plane。Vastora Agent 运行在每个受管 Node 上，并将该 Node 接入 Control Plane。
